# Visitor desk surface brief

Mode: operate (guard desk, host approval, admin console). Seed key 8a99ecb4, assigned candidate 3.

## Direction contract

THESIS: A gate sign, not a dashboard. Everything a guard or admin needs is read the way a transit sign is read: one signal colour owns wayfinding, the next decision is the largest thing on screen, and state is never carried by colour alone.
OWN-WORLD: Warm paper ground (#F3F1EA), near-black ink (#151515), signal yellow (#FFC20E) used only for the header band, the primary action, and the active navigation item. Status uses text plus colour: green inside/approved, red rejected/alert, amber stale. Humanist sans in sentence case; numerals are tabular.
STORY: The guard captures a visitor and sends one approval request; the host approves on their phone; the guard sees a large pass number and prints the sticker. Later the guard or admin sees exactly who is inside and closes every exit.
FIRST VIEWPORT (guard, phone): yellow header band with site name and inside count, a two-tab segmented bar (Check in / Inside), then the check-in form with the next required field in focus. Primary action sits at the bottom, full width.
FORM: Operate, admin-console density, with the signature move being the monumental pass number on the approval result (gate-number scale). Seed key 8a99ecb4, candidate 3 of the grounded list.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
